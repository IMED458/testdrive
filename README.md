# მართვის პრაქტიკული გამოცდის სიმულატორი

ქალაქში მართვის პრაქტიკული გამოცდის მოსამზადებელი ვებ-სიმულატორი.
პირველი ეტაპი — **თელავი, B/BE კატეგორია, 5 ოფიციალური მარშრუტი**.

> ეს არ არის საქართველოს შსს-ს ან მომსახურების სააგენტოს ოფიციალური პროდუქტი
> და არ ცვლის რეალურ პრაქტიკულ გამოცდას.

## გაშვება

```bash
npm install
npm run dev
```

## მონაცემების სანდოობა

თითოეულ მარშრუტს აქვს `trust` ველი და ინტერფეისში ჩანს, რომელი მონაცემია დადასტურებული:

| დონე | მნიშვნელობა |
|---|---|
| `OFFICIAL_DOCUMENT` | პირდაპირ ოფიციალური ბრძანებიდან |
| `MANUALLY_VERIFIED` | ხელით გადამოწმებული წყაროსთან |
| `ESTIMATED` | სავარჯიშო მიახლოება — **ადგილზე გადამოწმებული არ არის** |
| `PENDING_REVIEW` | წყაროზე ბუნდოვანია, დადასტურებას საჭიროებს |

**მარშრუტების GPS-ხაზი ამჟამად `ESTIMATED`-ია.** ოფიციალური წყარო არის რასტრული რუკა
(№598 ბრძანება), არა GPS-მონაცემი. ქუჩების სახელები ოფიციალური ჩამონათვალიდანაა,
კოორდინატები კი სავარჯიშო მიახლოებაა და ადგილზე უნდა გადამოწმდეს.

## Firebase

პროექტი: `testdrive-de93a`. გამოიყენება Auth, Firestore და Storage.

უსაფრთხოების წესები **აუცილებლად უნდა განთავსდეს** — ვებ-კონფიგი საჯაროა,
ნამდვილი დაცვა წესებზეა:

```bash
firebase deploy --only firestore:rules,storage
```

- `firestore.rules` — მომხმარებელი როლს თავად ვერ იცვლის; ინსტრუქტორი ხედავს მხოლოდ თავის მოსწავლეებს
- `storage.rules` — ხმას ტვირთავს მხოლოდ ადმინი, მხოლოდ audio/* 5 მბ-მდე
